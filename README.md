# Flipanion

**Flipanion** ist eine Lernplatform zum Erstellen und Wiederholen von Lerninhalten. Dieses Repository enthält ein Prisma-basiertes Backend (Deno/Prisma) und ein Next.js-Frontend (React + Supabase Auth).

## Projektstruktur (Kurz)

- `Flipanion Prisma Backend/` – Prisma-Schema, Deno-Skripte zum Migrieren/Seeden der DB und Prisma Client
- `Flipanion React Frontend/flipanion/` – Next.js-App (React) mit Supabase-Integration

- Genauere Informationen findet man in den README.md Dateien des jeweiligen Projektabschnitts.
